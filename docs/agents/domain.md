# 领域文档

本项目采用单一上下文布局：
- GLOSSARY.md：位于根目录，定义领域术语。
- docs/adr/：记录架构决策。

## 阅读规则

探索代码前，阅读 GLOSSARY.md 和与当前工作相关的 ADR。
如果文件尚不存在，直接继续，不提示缺失，也不提前创建。
领域术语或决策明确后，由 domain-modeling 技能按需创建。

## 术语规则

议题、设计建议、测试名称等应使用词汇表定义的术语，
避免使用词汇表明确排除的同义词。
发现真实的术语缺口时，记录给 domain-modeling 处理。

## 决策冲突

方案与现有 ADR 冲突时，明确指出对应 ADR 和重新讨论的原因，
不得默默覆盖已有决策。
