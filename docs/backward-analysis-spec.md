# 观察相关后向切片线索：前端交付规格

当前边界依据 [ADR-0002](adr/0002-mock-oriented-backward-evidence.md)。2026-11-17 用户明确取代此前“完整执行解释／Mock 规格”要求。本页是当前前端接口与验收边界的唯一说明；原设计保留于 Git 历史，不再作为本轮完成门槛。

## 目标

输入审核后的 Masked Test 和待测函数，从原始观察向后输出相关代码切片、数据/控制/状态/调用依赖，以及每条关系的前提、证据和 UNKNOWN。不发明原测试未要求的行为；不要求前端输出完整路径、Mock 响应或具体测试替身实现。

## 输入与身份

保留 case/dataset/snapshot、masking、原观察 ID、源码角色与摘要。入口来源必须区分自动恢复、任务提供和诊断覆盖。源码只从既有审核 Adapter 读取；未读取或身份改变的代码不能用作证据。不以修改数据集、恢复隐藏测试或读取 gold 解决分析缺口。

## 输出结构

独立版本 `mock-spec.slice-evidence/v1`，不向旧严格 v1 关系报告静默增添字段。

| 字段 | 内容 |
| --- | --- |
| identity | 案例及冻结输入身份、入口来源 |
| sources | 可见源码身份、路径、摘要及坐标范围 |
| contexts | 调用或参数行上下文，互斥上下文不合并 |
| evidence | 原文片段及坐标、分析规则或绑定来源；原文需与审核源码一致 |
| observations | 原观察 ID、原表达式及来源；不得扩大测试要求 |
| slice_nodes | 被保留的语句、条件、调用、观察；精确源码位置和上下文 |
| premises | 分支方向、调用绑定、正常完成等适用前提及证据 |
| relations | 数据/控制/状态/调用依赖、端点、观察、上下文、前提、证据和 grounded/conditional 状态 |
| unknowns | 未解析调用、别名、异常、外部状态、预算截断等边界，注明影响范围 |
| exclusions | 已否定或拒绝的关系及理由；不作为 Agent 可消费依赖 |
| coverage | 实际分析范围及未覆盖内容，不虚构路径覆盖率 |
| cost | 本次输入、分析与投影成本；缺失成本明确记录 |

Grounded 只用于所声明边界内有直接依据的事实。带未建立前提的推导必须保留 conditional；未知不伪装成依赖不存在。关系级证据不能由模型自信度、后端完成状态或格式校验授予。

代码片段是不可执行的切片展示，不能通过补代码把它包装为完整程序。保持源级行列坐标，不将相邻多个调用折叠。结构校验负责引用、坐标、原文、上下文与状态一致性，语义可靠性依赖独立正反验收。

## 必须保持的性质

1. 从真实观察出发，不从预设 Mock 行为倒推目标。
2. 实参、形参、返回值和字段关系只能在有依据的调用/对象身份下连接。
3. 不把后发生调用连接为先前观察的原因；不混合不同调用返回上下文。
4. 不把不同参数行或互斥分支的事实拼成一个条件集合。
5. 确定覆盖不能保留旧来源；返回后修改对象不能反推为返回时已经具有该状态。
6. 复杂表达式可原样保留，无法推导就 UNKNOWN；不以补造状态/异常行为让分析完成。
7. 源码行为事实不自动变成新增验证要求，依赖发现不自动授予替换权限。
8. 所有原观察及失败/UNKNOWN/预算状态保留；不得以空结果或缩小分母取得门禁通过。

## 小范围验收与下一阶段

局部台账沿用 [原案例集](../experiments/backward-slicing/spec-acceptance.md)：flask_301、langflow_186、crawl4ai_448/449、hummingbot_416、Jib、Hadoop。逐例区分 pass/unknown/fail；不要求全部关系完整，但禁止已知错误关系进入消费物。

门禁需同时具有 Python 正例、Java 正例及 Java 时序负例。flask_301 保留三个原观察和四个参数行；Jib 只接受已核验关系，原19观察和边界保留；Hadoop 必须拒绝晚于 Random89 的 append/flush/token 事件对该观察的影响。其余案例按真实证据报告，不以旧 analysis_may 直接升格。

门禁通过后锁定具体实现与消费物摘要，在同批有用切片样本上开始用户授权的 Agent A/B：A=原始测试和源码，B=A+切片线索。源码访问、模型、预算、评价与修复机会配对一致。先报告错误类型与逐例变化，不预设提升或以少量样本证明普遍有效性。若 Java 正向/反向门禁未通过，不启动依赖该门禁的 A/B；明确记录仍缺少的证据。

## 当前实现关系

[flask_301 局部原型](../experiments/backward-slicing/results/flask301-local-constraints/report.md)可复用参数行、分支与直接返回来源，不把其中的返回要求字段当作新前端必需输出。旧 WALA/CodeQL 报告保留为原始材料；未经核验关系不能自动转换为 grounded。生产 Scenario Agent、旧数据集和历史实验记录保持原有身份。
