# 研究入口交付场景依赖规格

本轮通过 staged-inference 研究入口交付版本化、自包含的依赖行为 spec，不要求接入生产 CLI。
继续复用审核输入、SourceStore、只读工具和正式 v0.1 契约；冻结 V0.1 不改。
正式契约保留条件式 Claim 的含义，研究 spec 将必要的范围、依据、假设、允许变化、未知及使用限制
与契约一起交付。完整调查轨迹用于审计，不作为理解规格的必要输入。

有证据支持、满足原始目标及依赖约定的多个分支可表达为合法替代，消费者选择一个完整分支。
相同最终返回值或未发现反证不足以建立合法性；未决的实质歧义仍限制消费。
旧研究状态 AMBIGUOUS 不能单独表达两者的区别，消费须使用新版 spec 的分支及交付状态。

当前冻结 MUT 是回归分析参考，不是已证明正确的业务规范。实现事实、测试要求、依赖约定和推导结论
分别保留依据，附加假设及其影响随规格交付。三类依据冲突时保留冲突，不用不合理 Mock 响应消除它。

五阶段保留职责，但构造和对照发现重要缺口时可以返回查询；候选可随证据修订，原始目标不随之缩减。
语义继续调查沿用整次预算和证据存储，与格式修复分开。这替代旧 PRD 中一次修订后禁止重新调查的约定。
