# 前端交付观察相关切片线索，后端 Agent 自主生成

2026-11-17 用户明确收敛前端目标。本决定替代此前要求前端交付完整执行解释和条件化 Mock 行为规格的范围；旧版本由 Git 历史保留。生产 ScenarioContract 不因此迁移。

前端接收审核后的 Masked Test、待测函数及明确的入口来源，从原始测试观察向后提取相关代码片段和数据、控制、状态、调用关系。每条关系保留源码证据、适用调用/参数行上下文、前提及 UNKNOWN 边界。不要求前端构造完整执行解释、穷举路径、求解外部行为或生成 Mock 规格；不依赖 SMT。

原测试要求、当前实现事实、带前提的依赖关系分别表达。源码中存在某语句不证明它影响观察；图可达不证明调用上下文匹配；结构化输出校验不证明语义。UNKNOWN 是明确的分析边界，不是无影响，也不是下游可自由编造事实的授权。

前端不能发明状态值、返回对象身份、调用次数、交互断言或替换权限。已被反例否定的关系进入排除记录，不得以候选或低置信度关系继续供消费者使用。时序倒置、互斥参数行混合、错绑调用和覆盖错误必须拒绝；其余不支持内容允许保留 UNKNOWN。

输出为独立版本的切片线索契约，与旧关系报告及局部约束原型分开；代码片段附来源和坐标，不冒充可执行测试。共同约束、完整路径和具体 Mock 响应不属于该前端契约。

先在既有局部验收集上固定版本验收，保持所有案例的状态台账。至少验证 flask_301 的正向切片、Java 正向观察关系和已知时序误连反例；不能以删除全部关系、仅输出 UNKNOWN 或改写测试要求取得通过。未支持案例不被计作能力成功，也不静默移出分母。

可靠性门禁通过后，用户已授权在通过且具有实际可消费线索的同批样本上进行 Agent 生成 A/B 对照：同一原始输入、模型配置、源码权限、生成/修复预算；B 仅额外获得切片线索，A 不获得。分析成本单列。Agent 自主查源码和生成 Mock；UNKNOWN 保留，不承诺 Agent 能解决全部未知。不得把局部静态分析验收直接报告为生成效果。

A/B 评价区分替换错误、返回/异常配置错误、状态遗漏、参数与交互错误、过约束及执行基础设施失败；没有充分评价依据时保留无法判定。测试通过不等于行为完全正确。定向变异可作为后续独立条件，但不是本次 A/B 的默认新增变量；变异存活也不自动授权新增断言。

沿用 ADR-0001：当前实现不是业务正确性标准。冻结数据、masking 和原观察保持不变；不恢复旧自动修复流程、不启动全量165例。门禁未通过时继续定位已授权的小范围问题，记录阻塞，不启动依赖该门禁的 Agent 实验。
