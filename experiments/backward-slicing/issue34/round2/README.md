## 逻辑链在哪里起了作用

三个候选都写了相同的四项交互断言。差异出在 Stub 对分支的设置，尤其是调用被测函数时哪个返回值实际生效。

| 预定观察 | A 自主探索 | B 完整切片 | C 精简导航 |
|---|---|---|---|
| 上下文查询选择分支 | 真分支内 patch 后返回 mock_ctx，随后在分支外再次 patch，同一查询最终对五行都返回 None | 真分支返回 mock_ctx，假分支返回 None | 被测调用前用条件表达式直接设置这两个返回值 |
| 应用 aborter 抛出异常并阻断回退 | 三个有上下文行全部误入回退；断言要求应用 aborter 调用一次，实际零次 | 三行都走应用路径；异常文本、实参、次数及未调用回退均通过 | 三行结果同 B |
| 无上下文的回退调用 | 两行均通过；包含 kwargs 的一行对丢失实参敏感 | 两行均通过；非空 kwargs 丢失被检出 | 两行结果同 B |

这一差异与导航所列的测试条件、产品守卫及异常传播关系一致。C 在没有额外源码调用的情况下恢复了正确路径。A 已写出正确的调用断言，却没有保持让该调用发生的前置条件。B 和 C 在本例的五行执行和三个变异上没有观察到差异。当前对照不能分离提示中的源码坐标、关系说明与采样波动各自的贡献。
