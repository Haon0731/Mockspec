# flask_308 第二轮预先约定

每组一次独立生成，主比较 A（无提示）与 C（三观察导航），次比较 B（全部 13 条关系）与 C。使用上一轮已冻结的三个提示和 read/search 接口。生成者无法访问以往输出、评阅、运行和变异。每组 600 秒、10 次源码调用；deepseek-flash 默认推理，每次响应拟限 32768 token，独立十槽样例验证后启用。正式生成无重试，无测试反馈。全部冻结后才对候选评分和执行。与先前 8192 token 实验分别报告。

逐组比较三个事先指定的行为：

1. 上下文查询返回值能否让给定五行选择相应产品分支。
2. 有上下文时是否由应用 aborter 抛出可见断言期待的异常；若约束回退调用，是否限定在适用分支。
3. 无上下文时是否由回退依赖产生可见异常，实际检查哪些转发实参，是否捕获非空 kwargs 丢失。

按原匿名规则报告完整匹配数/可判定参考项数、等价效果和附加限制。记录生成交付率、原程序五行、每个变异逐行配对。原程序 5/5 并通过身份核对才计算检出数/3。相同行为照实记录，不以代码风格替代行为差异。

一次独立的非目标 Docker 环境预检。正式容器串行，原程序与三个变异各一次。每次启动预算 120 秒，pytest 预算 60 秒，记录各参数行进度。保持固定镜像、冻结只读输入、断网、1 CPU、768 MiB。不同时运行仓库测试。模型或容器失败均保留原始回执。
